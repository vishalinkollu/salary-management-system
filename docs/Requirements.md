Employee Salary Management System

//======================//
Goal

Provide HR Managers with a web application to manage salary information for 10,000 employees across multiple countries.

//======================//
User Persona

=> HR Manager

//=====================//
=> Core Features
 (a) Employee Management
 (b) Add Employee
 (c) Edit Employee
 (d) Delete Employee
 (e) Employee Details
 (f) Salary History
 (g) Search Employees
 (h) Filter by Country
 (i) Filter by Department
 (j) Filter by Status
 (k) Pagination
 (l) Dashboard Metrics

 => Non Functional Requirements
 (a) Support 10,000 employees
 (b)Fast search experience
 (c)Maintainable architecture

//=====================//
=> Out Of Scope

Authentication
Role Based Access
Payroll Processing
Email Notifications
Audit Logs
Bulk Upload
Reasoning

Focus was placed on core employee salary management functionality while keeping implementation simple and maintainable.
